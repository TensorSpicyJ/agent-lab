# wen-kmatrix-multilevel-suite

This task converts Wen's K-matrix/topological-order discussion into a
multi-level benchmark:

- Level 1: formula application;
- Level 2: local quotient-lattice derivation;
- Level 3: bridge graph from source claims to GSD;
- Level 4: section-level connection between bulk sectors and edge chirality.

It is intended to test whether an agent can connect different pieces of the
paper without requiring full article-level reconstruction.

Run:

```powershell
python benchmarks/v0.1-known-results/tasks/wen-kmatrix-multilevel-suite/verify.py <answer.md>
```
