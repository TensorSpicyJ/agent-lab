# Gold: Toric Code Ground-State Degeneracy on a Torus

## Final Result

The toric code has ground-state degeneracy

```text
GSD = 4
```

on a torus.

## Minimal Accepted Derivation

One accepted route:

1. The toric code Hamiltonian is built from commuting star and plaquette
   stabilizers.
2. The ground space is the simultaneous +1 eigenspace of all independent
   stabilizers.
3. On a torus there are two independent non-contractible cycles.
4. Logical Wilson loop operators around these cycles commute with the
   Hamiltonian but are not generated by local stabilizers.
5. The two independent logical qubits give `2^2 = 4` ground states.

Equivalent stabilizer-counting route:

1. For a square lattice on a torus with edges as qubits, let `E`, `V`, and `F`
   be the numbers of edges, vertices, and plaquettes.
2. There are `V` star and `F` plaquette constraints, but two global products
   are redundant.
3. Number of encoded qubits is `E - (V + F - 2)`.
4. On a torus, Euler characteristic gives `V - E + F = 0`, so
   `E - V - F + 2 = 2`.
5. Therefore the ground space dimension is `2^2 = 4`.

## Required Assumptions

- Closed torus topology, not plane or sphere.
- Standard toric code with qubits on edges.
- Stabilizers commute.
- Ground states satisfy all stabilizer constraints.
- No boundary or perturbation that splits the topological degeneracy.

## Physics Checks

Good answers should include at least two of:

- topology check: genus `g` surface has `GSD = 4^g`, giving `4` for `g=1`;
- sphere check: genus `0` gives no topological degeneracy;
- locality check: local stabilizers cannot distinguish the four sectors;
- logical operator check: two independent non-contractible loop pairs encode
  two logical qubits;
- robustness caveat: finite perturbations may split degeneracy exponentially
  in system size but do not change the ideal exactly solvable result.
