# agent-lab

研究怎么做好的 agent 和怎么写 harness。实验场。

## 核心问题

- 什么是一个"好"的 agent？能力边界、可靠性、可组合性
- harness 应该提供什么？工具协议、状态管理、错误恢复、人机交互
- 从现有项目（AITP、literature-lab、superpowers）中提炼可复用的模式

## 目录

| 目录 | 内容 |
|------|------|
| `research/` | 分析笔记：agent 设计模式、harness 架构 |
| `experiments/` | 可运行的实验 agent |
| `specs/` | harness 接口规范草案 |
