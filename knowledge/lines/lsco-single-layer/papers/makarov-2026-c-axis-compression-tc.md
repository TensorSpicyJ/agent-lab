# Non-monotonic dependence of Tc on the c axis compression in LSCO

## 一句话结论
c 轴压缩通过 a1g 轨道抬升→与 b1g 相互作用增强→态密度增加→提升 Tc，
同时配对常数重整化→抑制 Tc，两种效应竞争导致 Tc 对 c 轴的非单调依赖。

## 关键发现
- c 轴压缩抬升 a1g 轨道能量，增强与 b1g 能带相互作用
- 与超导相关的态密度在费米能级附近升高，欠掺杂区有利于 Tc 提升
- 配对常数重整化同时抑制 Tc——两种效应在近最佳掺杂区产生非单调 Tc
- 在欠掺杂区间 Tc 的变化趋势与最佳掺杂附近相反

## 与我们的关系
- **涉及线**: LSCO 单层
- **支撑假说 H1**: c 轴压缩通过带结构重构提升 Tc
- **对 H2 的影响**: 提供理论框架解释封帽应变→c 轴→Tc 的链路
- **适用边界**: bulk/bulk-like LSCO，超薄区(<4 u.c.)需额外考虑量子限域修正
