# Quantum interference in a twisted high-Tc SQUID senses emergent interfacial order

## 一句话结论
扭转 BSCCO 界面 SQUID 测量到 π 相位差，支持 emergent interfacial superconducting order
with time-reversal symmetry breaking——界面工程可从调 Tc 升级到改写序参量结构。

## 关键发现
- 扭转 BSCCO 界面 SQUID 两臂间观测到 π 相位差
- 磁场调制 switching current + differential resistance 结果支持 TRSB interfacial order
- 接近 77K 的磁通噪声灵敏度——不只有概念也有测量平台价值
- 对 LSCO 线的启示: 界面可能改写的不只是 Tc，而是序参量对称性本身
